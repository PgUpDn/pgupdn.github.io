A research harness that gets better at research.

Give HELIX a scientific task, its data and a scoring rule, and it runs the research loop end to end: it proposes approaches, builds and trains them, scores them for real, keeps what works, and audits its own results before it reports back.

What it does

From task to audited result, without a human in the loop.

HELIX treats research as a loop to be run, measured and improved, not a script to be executed once.

Runs the whole loop

Proposes candidate approaches, implements them, trains and evaluates them, then iterates. Two independent solvers work each task and their best results are merged.

Scores everything for real

Every candidate is run against your actual data and your actual scoring rule. Nothing is kept on the strength of a plausible-sounding argument; only measured improvement survives.

Audits itself before it reports

Before a number reaches you, HELIX re-checks it against the standard we hold ourselves to. Results that fail that check are withdrawn, however good they look.

How it works

Two loops, one of which improves the other.

Most agents run a single loop: try something, look at the result, try again. HELIX runs two, and the outer one is what makes the system compound.

The outer loop — the science

It spans runs. It asks what is actually limiting progress, forms a view about why, tests that view against measurement rather than intuition, and keeps what it learned.

The inner loop — the engineering

selectgenerateevaluatekeep the winners

It runs inside a single problem. Candidates are built and scored against the real scoring rule, not a proxy, and only measured winners survive.

Recursive self-improvement

The system doing the research is the system being improved by it.

Within a run

Every measured result changes what is tried next. Progress inside a problem is driven by evidence the run produced minutes earlier, not by a plan written before anything was known.

Across runs

What the outer loop learned about a class of problems — which approaches pay off, which dead ends to skip, what a suspicious result looks like — carries into the next problem. The harness is better at the second problem than it was at the first.

Heuristic learning

It learns rules of thumb, not just models.

A model fitted to one dataset is worth something once. A heuristic — a compact, reusable judgement distilled from experience — is worth something every time a similar problem appears.

What to try first

Which family of approaches tends to pay off for a given shape of data, and which is usually a waste of the first hour.

What to distrust

When a result is too good to be true, and which quirks of a dataset tend to produce numbers that will not survive scrutiny.

When to stop

When tuning has stopped paying and the honest move is to change direction rather than push the same idea further.

These are retrieved when they are relevant, rather than carried along as ever-growing context. The agent starts each problem informed, not burdened.

Integrity

We audit ourselves before we report.

A research system that only reports its wins is not a research system. Before HELIX reports anything, it goes back over its own work and asks whether each result was really earned: whether it came from a method genuinely fitted to the problem, or leaned on something it should not have.

Results that cannot be cleared are withheld — including its own best ones. That has happened, and it is the point: an agent that cannot rule against itself cannot be trusted when it rules in its own favour.

Every score HELIX reports was measured against the real scoring rule for the problem, never estimated.
